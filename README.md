# Elixir Functions Practice

This project demonstrates foundational Elixir function concepts,
including named functions, anonymous functions, pattern matching, guard
clauses, and multiple function clauses. It includes small examples such
as classifying values and using guards to choose behavior based on
input.

## Instructions for Build and Use

Steps to build and/or run the software:

1.  Install Elixir and verify the installation with `elixir --version`.
2.  Save the Elixir source code in a `.ex` or `.exs` file.
3.  Run a script from the terminal with `elixir filename.exs`. For
    interactive experimentation, start IEx with `iex`.

Instructions for using the software:

1.  Define modules and named functions with `defmodule` and `def`.
2.  Call the functions with test inputs and use `IO.inspect/1` when you
    want to display returned values from a script.
3.  Experiment with different inputs to observe how pattern matching,
    guards, and function-clause order affect which clause executes.
